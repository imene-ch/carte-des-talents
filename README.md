# SkillSphere

Built during **Nuit de l'Info**, a hackathon-style coding challenge, as a group project with [Rihem](https://github.com/Rihem-123).

A talent showcase platform where users create a profile, list their skills with proficiency levels, and document past projects — built as a group project.

## Overview

SkillSphere lets users build a professional profile centered around **skills and project history**, rather than just a static resume. Each profile shows contact info, a bio, a tagged list of talents, and an expandable history of past projects with role, description, and technologies used.

## Pages

| Page | Description |
|---|---|
| `page d'acceuil.html` | Landing page with animated gradient background and entry points to sign up or log in |
| `inscription.html` | Sign-up form — name, email, nationality, address, phone (with country code selector), password, and profile photo upload |
| `login.html` | Login form |
| `profile.html` | Main profile page — bio, contact info, skill tags, accordion-style project history, and forms to add new talents/projects |
| `modifierprofile.html` | Edit-account modal — update phone, email, address, and password |

## Features

- **Skill tagging** — users add talents with a name and proficiency level (Beginner / Intermediate / Expert), optionally attaching a file as proof of the skill
- **Project history** — an accordion list of past projects, each with role, description, and tech stack, with a form to add new entries
- **International phone input** — country-code dropdown covering 20+ countries paired with the phone field
- **Profile photo upload** — circular upload zone with hover feedback
- **Consistent dark/neon visual theme** — animated gradient backgrounds, glow effects on inputs and buttons on focus/hover, used consistently across every page

## Tech Stack

`HTML` `CSS` `Bootstrap 5` `Bootstrap Icons` — no backend; form submissions are static/demo-only
